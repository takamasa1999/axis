# Contract: デザインシステム（ポップでわかりやすく）

**Plan**: [../plan.md](../plan.md) | 対応：原則VIII、FR-047〜FR-050

## コンセプト：「気軽に、あかるく、まっすぐ」

- **気軽に**：掲示板に貼られた付箋やチラシのようなカード。かしこまらない言葉づかい
- **あかるく**：黄色を主役にした元気な配色、丸みのある文字と形
- **まっすぐ**：飾りすぎない。大事な情報（給与・勤務地・時間）が一目で分かる。労働条件はきちんと読める

見た目の特徴は「黒い太めのふち取り＋少しずらした影」。押せるもの・カードがはっきり分かり、楽しさも出る。

## 文字

| 用途 | 書体 | サイズ・太さ |
|------|------|--------------|
| 全体 | Zen Maru Gothic（丸ゴシック、Google Fonts） | 本文 16px 以上、行間 1.8 |
| 見出し | 同上 | 太さ 700。ページ見出し 28px、カード見出し 18px |
| 数字（給与など） | 同上 | 太さ 700、20px 以上で目立たせる |

- 1行は全角35文字程度まで。長い労働条件は見出し付きの項目に分ける

## 形とうごき

| 要素 | ルール |
|------|--------|
| カード | 角丸 16px、2px の `--ink` のふち取り、影 `4px 4px 0 var(--ink)`。押すと影が `2px 2px` に縮み、少し沈む |
| ボタン | 角丸いっぱい（ピル型）、高さ 48px 以上、2px のふち取り＋影。主ボタンは `--sun` |
| 入力欄 | 角丸 12px、2px のふち取り、高さ 48px 以上。フォーカス時は `--sky` の太い輪郭 |
| チップ（職種・条件） | ピル型、薄い色の背景＋アイコン |
| 動き | 0.15 秒程度の小さな動きだけ。`prefers-reduced-motion` のときは動かさない |

- 押せる場所は 44×44px 以上（スマートフォン）
- フォーカスの輪郭を消さない

## 画面の構成

- **スマートフォン優先**。ログイン後は画面下に4つのタブ：「さがす」「メッセージ」「投稿する」（求職者は求職の投稿、企業は求人）「マイページ」
- PC では上部にナビゲーション、本文は最大幅 1040px
- 求人カードに出すもの（上から）：職種のチップ → タイトル → 企業名 → 給与（大きく）→ 勤務地・雇用形態 → 掲載日
- 空の状態（求人がない・メッセージがない）には、小さなイラストと「次にやること」のボタンを置く

## ことば

| 原則 | 例 |
|------|-----|
| 短く、やさしく | 「応募する」「質問してみる」「声をかける」 |
| 専門用語には言い換えと説明 | 「就業場所の変更の範囲」→ 見出し「将来、働く場所が変わる可能性」＋説明「入社後に配属や転勤で変わる可能性がある範囲を書いてください」 |
| 命令しない | ×「入力してください」→ ○「〇〇を教えてください」 |
| エラーは理由と直し方をセットで | 「給与の下限が上限より大きくなっています。金額を見直してください」 |
| 法令の注意はやわらかく、でもはっきり | 「『女性歓迎』は法律で使えない表現です。『どなたでも歓迎』などに言い換えてください」 |

## 実装の方針

- 色・角丸・影は CSS 変数（`src/app/globals.css` のトークン）で定義し、Tailwind のテーマから参照する
- shadcn/ui の部品（button・card・input など）の見た目を、このトークンに合わせて調整する
- アイコンは lucide-react。イラストは軽い SVG をリポジトリに置く（外部の画像サービスに依存しない）
- 書体は `next/font/google` で読み込み、自前で配信する（表示の崩れと外部への通信を避ける）
- ダーク表示は OS の設定に合わせる（トークンを切り替えるだけ）
