# Contract: 求人・投稿の掲載ルール（法令対応）

**Plan**: [../plan.md](../plan.md) | **Spec**: [../spec.md](../spec.md)

`src/server/compliance/` に1か所で実装し、画面の入力チェック・サーバーの検証・テストで同じ定義を使う。
**ここに載せた語句の一覧・例外理由の文言は、公開前に専門家（弁護士・社会保険労務士）の確認を受ける。**

## 1. 求人の必須項目（FR-009、職業安定法第5条の3・同施行規則）

公開（`publishJob`・公開中の `updateJob`）のとき、次がすべて満たされていなければ `VALIDATION` で止め、足りない項目を返す。

| 項目 | ルール |
|------|--------|
| 募集する企業の名称 | 企業プロフィールの企業名（自動で表示） |
| 業務内容 | 1〜3000文字 |
| 業務内容の変更の範囲 | 1〜500文字（変更がない場合は「変更なし」） |
| 雇用形態 | 正社員・契約社員・パート/アルバイト・派遣のいずれか（派遣の場合は求人に「派遣」と目立つ表示） |
| 契約期間 | 無期 or 有期。有期なら期間・更新の有無・更新の上限（上限なしなら「なし」）が必須 |
| 試用期間 | 必須（なしなら「なし」） |
| 就業場所 | 都道府県・市区町村が必須。リモートの有無 |
| 就業場所の変更の範囲 | 1〜500文字（変更がない場合は「変更なし」） |
| 始業・終業時刻 | 必須（シフト制ならその説明） |
| 時間外労働 | 有無が必須。ありなら目安の説明 |
| 休憩 | 必須 |
| 休日 | 必須 |
| 賃金 | 種類（時給・日給・月給・年俸）と下限額が必須。上限があれば下限以上。固定残業代ありなら、時間数と金額、超えた分を追加で支払う旨を `salaryNote` に必須 |
| 加入する保険 | 雇用保険・労災保険・健康保険・厚生年金のうち該当するもの（何も選ばない場合は確認のダイアログを出す） |
| 受動喫煙を防ぐための措置 | 必須（屋内禁煙・喫煙室あり・対策なし・その他） |
| 確認事項 | 「内容は事実です」「法令に違反していません」「ストライキや作業所閉鎖が行われている事業所ではありません」の3つにチェック（FR-013、指針 第六の二(四)） |

## 2. 性別を限定する表現（FR-011、男女雇用機会均等法）

| 区分 | 語句の例 | 動作 |
|------|----------|------|
| 公開を止める | 男性のみ、女性のみ、男性限定、女性限定、男性歓迎、女性歓迎、男性募集、女性募集、男子のみ、女子のみ | 該当箇所を示し、修正するまで公開できない |
| 注意を出す（言い換えを提案） | 営業マン→営業職、ウェイトレス/ウェイター→ホールスタッフ、看護婦→看護師、保母→保育士、主婦歓迎→主婦・主夫歓迎、OL→事務職 | 注意を表示。修正しなくても公開できる |

- 性別を選ぶ入力項目は作らない
- 法令上の例外（ポジティブ・アクションなど）による性別の限定は、初期はサポートしない（必要ならお問い合わせで個別に相談）

## 3. 年齢の条件（FR-012、労働施策総合推進法第9条・同施行規則第1条の3）

年齢の条件（`ageMin`・`ageMax`）は、次の例外理由のどれかを選んだときだけ入力でき、選んだ理由を求人に表示する。

| コード | 例外理由（表示する文言の案） |
|--------|------------------------------|
| `RETIREMENT_AGE` | 定年年齢を上限として、その年齢未満の方を期間の定めのない雇用で募集するため（1号） |
| `LEGAL_RESTRICTION` | 法令で年齢の制限が定められている業務のため（2号） |
| `YOUTH_CAREER` | 長期のキャリア形成のため、若年者などを期間の定めのない雇用で募集するため（3号イ） |
| `SKILL_SUCCESSION` | 技能・ノウハウを継承するため、労働者が少ない特定の年齢層を期間の定めのない雇用で募集するため（3号ロ） |
| `ARTS` | 芸術・芸能の分野で、表現の真実性などが求められるため（3号ハ） |
| `SENIOR_PROMOTION` | 60歳以上の方、または国の雇用促進施策の対象となる年齢層に限って募集するため（3号ニ） |

- 本文に「〇歳まで」「〇〜〇歳の方」「若い方」などの年齢を限定する表現があり、例外理由が選ばれていなければ注意を表示して公開を止める

## 4. 求職の投稿の連絡先の検出（FR-033）

| 検出するもの | パターンの例 | 動作 |
|--------------|--------------|------|
| メールアドレス | `xxx@yyy.zz` 形式 | 注意を表示（「連絡先は書かないでください。企業とはメッセージでやり取りできます」）。確認すれば公開できる |
| 電話番号 | `0` で始まる 10〜11 桁（ハイフン・全角数字を含む） | 同上 |
| 外部の連絡手段 | 「LINE」「ライン ID」「インスタ」など | 同上 |

## 5. 掲載期間と最新性（FR-014、職業安定法第42条）

- 公開・延長の日から最長60日で `expiresAt` を設定し、`job-expiry` ジョブで自動的に掲載を終える
- 一覧と詳細に「掲載日」「最終更新日」を表示する
- 求人の内容（労働条件・本文）を変えたら `contentUpdatedAt` を更新し、新しい版を作る
- 応募者がいる求人で、次の項目が変わったら応募者に知らせる（FR-015）：業務内容・変更の範囲・雇用形態・契約期間・就業場所・時間・休憩・休日・賃金・保険

## 6. 運営による対応（FR-016、指針 第三の二）

- 運営は求人の内容を書き換えない。できるのは「修正依頼（期限付き）」「非公開」「非公開の解除」だけ
- 修正を依頼する理由：①公衆衛生・公衆道徳上有害な業務 ②内容が法令に違反 ③実際の業務内容などと異なる（指針 第三の二(一)イ〜ハ）
- 修正依頼の期限（既定3日）までに更新されなければ、運営の画面に表示し、運営が非公開にする

## 7. 職業紹介に当たる行為をしない（原則VII、指針 第五の六(二)）

設計・実装のレビューで、次がないことを確認する（PR のチェックリストに入れる）：

- [ ] 一覧・検索の並び順・絞り込みは、画面に名前で示した客観的な基準だけで決まる
- [ ] 運営やシステムが、運営の判断で特定の求人・求職者を選んで表示・通知・推薦していない（新着通知は本人が保存した条件だけ）
- [ ] 運営から求職者に求人を、企業に求職者を連絡する機能がない
- [ ] メッセージの本文を運営・システムが書き換えていない（SYSTEM メッセージは利用者の本文と別に保存）
- [ ] 求職者から料金を受け取る処理がない
